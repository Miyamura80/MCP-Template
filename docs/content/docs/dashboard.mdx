---
title: Dashboard deep links
description: Links an agent can give you to finish something only a person should do
---

Some things an agent should never do for you, such as minting a credential or
approving a dangerous call. For those, the agent gives you a link to a
dashboard page that is already filled in; you check it and click.

Opening a link never changes anything. Each page needs you signed in (WorkOS;
see [Approvals](/docs/mcp/approvals) for the sign-in setup) and a click on its
button.

## Create an API key

```text
/dashboard/settings/api-keys/create?name=ci-bot&expiration=30d&scope=read_only
```

| Parameter | Values | Default |
|-----------|--------|---------|
| `name` | up to 100 characters | empty |
| `expiration` | `none`, or `1d` to `365d` | `none` |
| `scope` | `read_only`, `standard`, `admin` | `standard` |

A value the page doesn't understand is ignored, with a note saying so. The new
key is shown once, after you click Create, and never appears in a URL. Send it
as the `X-API-KEY` header.

`/dashboard/settings/api-keys` lists your keys and revokes them.

## Approvals

| Link | Page |
|------|------|
| `/dashboard/approvals/{id}` | one held dangerous call: its exact arguments, Approve or Deny |
| `/dashboard/approvals` | every held call |
| `/dashboard/approval` | your approval mode and per-tool overrides |
