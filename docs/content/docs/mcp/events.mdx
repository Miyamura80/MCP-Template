---
title: Events
description: Let agents hear about approvals, feedback and new mail without polling tools
---

The server implements the MCP Events extension
(`io.modelcontextprotocol/events`). A client can poll for events, or register a
webhook, instead of calling tools in a loop to see whether something changed.

## Event types

| Name | Fires when | Arguments |
|------|-----------|-----------|
| `approval.resolved` | a held dangerous call is approved or denied ([Approvals](/docs/mcp/approvals)) | `tool` (optional) |
| `feedback.received` | your `feedback` submission is stored | none |
| `gmail.message_received` | new mail arrives (after `gmail_watch_start`) | `from` (optional, substring) |

`events/list` returns each type's `inputSchema` and `payloadSchema`. Every
event is the authenticated principal's own; there is no way to see another
user's.

A background agent that hit a browser-mode approval can subscribe to
`approval.resolved` and retry the held call when the event says `approved`.

## Poll

```json
{"method": "events/poll", "params": {"name": "feedback.received", "cursor": null}}
```

A `null` cursor starts from now. Keep the `cursor` from each result and send it
back; `hasMore: true` means poll again at once, otherwise wait `nextPollMs`.
Events are kept for 7 days (`events.retention_days`); a cursor from before
what was deleted comes back with `truncated: true`, the signal that some events
may have been missed. Cursors are per user and only ever move forward, so an
event that commits late is never skipped.

## Webhook

```json
{
  "method": "events/subscribe",
  "params": {
    "name": "approval.resolved",
    "delivery": {"mode": "webhook", "url": "https://you.example/hooks/mcp",
                 "secret": "whsec_<base64 of 24-64 random bytes>"},
    "ttlMs": 86400000
  }
}
```

- **You choose the secret.** The server stores it encrypted and never returns
  it.
- **Verification.** Before the first delivery to a URL, the server POSTs
  `{"type": "verification", "challenge": "<nonce>"}`; answer `2xx` with
  `{"challenge": "<nonce>"}`. A verified URL is trusted for a day.
- **Signing.** Deliveries follow [Standard Webhooks](https://www.standardwebhooks.com/):
  `webhook-id`, `webhook-timestamp`, and `webhook-signature: v1,<base64
  HMAC-SHA256>` over `{id}.{timestamp}.{body}`, keyed by the bytes after
  `whsec_`. Retries keep the same `webhook-id`, so dedup on it.
- **Refresh.** A subscription lasts `ttlMs` (default 1 day, at most 7). Call
  `events/subscribe` again with the same arguments before `refreshBefore`;
  that is the same subscription, not a new one.
- **Retries.** A non-2xx answer is retried, for 4 attempts in all over about
  11 minutes (1, 3 and 7 minutes apart). `410` and `413` stop retries for that
  event.
- **Limits.** 50 subscriptions per user (`events.max_subscriptions_per_user`).

## Push

A client that keeps a connection open can have events pushed instead, which is
how a host wakes an agent thread on an event:

```json
{"method": "events/stream", "params": {"name": "approval.resolved", "cursor": null}}
```

The response is a stream. It opens with `notifications/events/active`
(`cursor`, `truncated`, `heartbeatMs`), then sends one
`notifications/events/event` per event, each with its own `cursor`, and a
`notifications/events/heartbeat` when there is nothing else to send. Every
frame, and the final result, carries
`_meta["io.modelcontextprotocol/subscriptionId"]`.

- **Heartbeats.** Every 30 seconds by default. Ask for another interval with
  `heartbeatMs`; it is clamped to 1 to 55 seconds rather than refused.
- **Access.** The server re-checks your credentials on every heartbeat. If the
  API key or token was revoked, it sends `notifications/events/terminated`
  (`Forbidden`) and ends the stream.
- **Limits.** 5 open streams per user (`events.max_streams_per_user`); one
  more is refused with `-32025` (`ResourceExhausted`).
- **Reconnecting.** The server ends a stream after 5 minutes
  (`events.stream_max_seconds`), and on deploys. Reconnect with the last
  cursor you received and nothing is missed. Disconnect to stop early.
