---
title: Overview
description: Connect AI assistants to use your tools via MCP
---

The MCP server lets AI assistants call your tools directly. Set it up once and any MCP-compatible client can use all available tools without manual copy-pasting.

Every client connects to the **streamable-HTTP** endpoint at `/mcp`. **Cloud clients** (claude.ai, Cowork, ChatGPT, Grok) run in a vendor's cloud and need your public deployment with [OAuth](/docs/mcp/oauth). **Local clients** (Claude Code, Cursor, VS Code, Codex) run on your machine and can also use an API key or `localhost`. See [Supported clients](/docs/mcp/clients) for the full matrix.

## Quick Start

1. Pick your client from [Supported clients](/docs/mcp/clients)
2. Browse the [available tools](/docs/mcp/tools)
3. Ask your AI assistant to use them
