title: Setup

The server is **remote-first** - by default `mycli-mcp` runs on **Streamable
HTTP**, which any modern MCP-aware Host can connect to over the network.
**Stdio is a fallback** for editor clients that only support spawning a
subprocess locally.

## Remote (recommended): Streamable HTTP

Start the server (locally for testing, or deployed to Smithery / Cloudflare /
Railway / your own infra):

```bash
mycli-mcp                                # binds to 127.0.0.1:8765/mcp by default
mycli-mcp --host 0.0.0.0 --port 9000     # override host/port for hosting
```

Then point your MCP client at the URL, e.g.
`http://localhost:8765/mcp` (local dev) or
`https://mycli.example.com/mcp` (hosted). Most modern Hosts (Claude Desktop /
Cowork, Cursor, VS Code, Claude Code, etc.) accept a URL field for
Streamable HTTP servers - consult your client's MCP docs for the exact field
name.

For Claude Code, for instance:

```json
{
  "mcpServers": {
    "mycli": {
      "url": "http://localhost:8765/mcp"
    }
  }
}
```

## Stdio fallback (local subprocess)

Use this only if your editor client doesn't support Streamable HTTP URLs.
Replace `/path/to/MCP-Template` with the actual path to your cloned repo.
Note the `--stdio` flag - without it the command would default to Streamable
HTTP and the editor's stdio pipe wouldn't speak the right transport.

<Tabs items={['Claude Cowork/Desktop', 'Claude Code', 'Cursor', 'VS Code', 'Codex', 'Gemini CLI', 'OpenCode', 'OpenClaw']} groupId="mcp-client">
<Tab value="Claude Cowork/Desktop">

Add to your Claude Desktop config file:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`
- **Linux**: `~/.config/Claude/claude_desktop_config.json`

```json
{
  "mcpServers": {
    "mycli": {
      "command": "uv",
      "args": ["--directory", "/path/to/MCP-Template", "run", "mycli-mcp", "--stdio"],
      "env": {}
    }
  }
}
```

Restart Claude Desktop after saving the config.

### Other MCP Clients

Any MCP-compatible client supporting Streamable HTTP can connect directly to
the server's `/mcp` URL. For stdio-only clients, spawn
`uv --directory /path/to/MCP-Template run mycli-mcp --stdio` as a subprocess.
